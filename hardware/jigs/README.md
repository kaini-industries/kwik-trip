# Programming fixtures

Add a fixture only after a measured pad map exists. Record the target PCB revision, pogo coordinates, connector keying, power switching, supported board faces, and strain relief. Support the PCB rather than pressing on e-paper glass or the FPC.

No fabricated CAD or guessed pogo spacing is included. The Frickl reference has example fixtures, but compatibility with these tags is unverified. Store future CAD source beside exported manufacturing files and a bench record.
