# Hardware records

Host boards and electronic tags have independent records. Start with a model record, then keep unit-specific observations in `inventory/*.local.json` (ignored). Templates describe the measurements needed; they are not completed verification reports.

Use [adding a tag to your collection](../docs/workflows/add-a-tag.md) for any manufacturer or model. The two tag records below are initial research examples; each additional hardware revision gets its own folder and profile.
