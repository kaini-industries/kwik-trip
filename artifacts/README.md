# Generated outputs

Firmware packages, converted images and test reports belong here; generated contents are ignored by Git. PlatformIO's intermediate builds remain under each project's `.pio/` directory.

The curated [Cardputer factory and application downloads](../firmware/releases/cardputer-adv/README.md) are deliberately committed under `firmware/releases/cardputer-adv/`. This directory remains for disposable/local outputs.

Use names that identify host versus target, hardware profile and build revision. Preserve original acquired firmware in `backups/`, not among reproducible build outputs. `tools/etag.py package` creates a new directory and never overwrites an existing one.
